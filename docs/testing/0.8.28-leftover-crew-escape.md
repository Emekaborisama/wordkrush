# 0.8.28 — leftover-crew escape on create and join

C-94 (0.8.26) removed the crew-home screen, so `TeamsScreen` stopped loading the
player's crew. Memberships created before that change stayed on the backend, so
a player who already owned or belonged to a crew hit "Already on a team" on
Create room with no UI left to leave or disband.

Create and join now call `clearExistingMembership(profileId)` first: the owner
disbands, a member leaves, and then the original create or join proceeds. The
results screen already applied that rule on rematch, so both paths share one
helper in `src/teams/api.ts`.

## Automated coverage

`src/teams/cleanup.test.ts` drives the helper against a faked `supabase.rpc` and
asserts the RPC order, which is what distinguishes the two roles:

| Case | Expected RPC order |
| --- | --- |
| Leftover owner creates | `my_team`, `disband_team`, `create_team` |
| Leftover member creates | `my_team`, `leave_team`, `create_team` |
| Leftover owner joins | `my_team`, `disband_team`, `join_team` |
| Leftover member joins | `my_team`, `leave_team`, `join_team` |
| No crew | `my_team` only |
| Membership read fails | `my_team` only |

The owner path also asserts `leave_team` is never called, because the server
rejects a leave from the owner with error 0007.

Run them with `npx vitest run src/teams`. Note that `src/teams/**` was missing
from the `include` list in `vitest.config.ts`, so these suites never ran before
this change; enabling them also surfaced a stale assertion in `codes.test.ts`
(`AB12CD` contains `1`, which the invite alphabet drops on purpose).

## Manual check against a live backend

Automated coverage fakes the RPC layer, so it proves the client's decision and
call order but not the server's own membership rules. To confirm end to end, a
Supabase-configured build is required (`EXPO_PUBLIC_SUPABASE_URL` and
`EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY`).

The QA repro is player `hummer`, owner of crew `OpenCrew`, invite code `WDVP6J`:

1. Sign in as `hummer`, who still owns the leftover `OpenCrew`.
2. Enter a room name and tap **Create room**.
3. Expect the room to open. In the network log, `my_team` is followed by
   `disband_team` and then `create_team`, and no "Already on a team" banner
   appears.
4. Repeat as a member of someone else's leftover crew: `leave_team` replaces
   `disband_team`.
5. Repeat both roles against **Join room** with a valid code, and against an
   invite link so the auto-join effect runs.
