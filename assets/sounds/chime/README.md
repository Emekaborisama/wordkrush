# Chime notes

`note1.wav` … `note8.wav`: one soft bell tone per step of a C-major pentatonic
scale (C5 D5 E5 G5 A5 C6 D6 E6), 0.36 s, mono 22.05 kHz. Synthesized for
WordKrush (a sine with a decaying octave and fifth), so there is no licence to
track. Wordfall plays the next note for each letter traced; Higher or Lower
climbs the scale with the streak. Retune in `scripts/synth-chimes.mjs`, then
run `node scripts/synth-chimes.mjs`.
